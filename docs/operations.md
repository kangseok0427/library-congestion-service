# 방문 현황과 휴관일 캘린더

관리자 페이지(`/admin`)에서 로그인 후 사용합니다.

## 홈페이지 방문 현황

- 오늘/누적 방문자 수와 오늘/누적 페이지 조회 수를 표시합니다. 한국시간 자정에 오늘 집계가 바뀝니다.
- 같은 브라우저의 방문자 쿠키를 기준으로 중복을 제거합니다. 같은 날 반복 방문은 오늘 방문자 1명, 누적 방문자도 1명입니다. 페이지를 다시 열거나 새로고침하면 조회 수만 늘어납니다.
- 다른 기기·브라우저, 쿠키 차단/삭제/만료는 새 방문자로 집계될 수 있습니다. 실제 사람 수의 정확한 집계는 아닙니다.
- 이용자 홈페이지를 열 때만 집계하며, 날짜 변경/막대 조회/관리자 페이지/API/알려진 검색 봇은 집계하지 않습니다. 기존 기간을 소급 집계하지 않습니다.
- IP·이메일을 저장하지 않습니다. 브라우저에는 임의 UUID 쿠키(HttpOnly/SameSite=Lax), 서버에는 SHA-256 해시와 날짜별 조회 수만 보관합니다. 집계 오류가 통계 조회를 막지 않습니다.

## 휴관일 캘린더

1. 이전/다음 달 버튼으로 원하는 달을 엽니다.
2. 날짜를 선택하고 필요한 경우 사유를 입력합니다(최대 80자).
3. **휴관일 등록**을 누릅니다. 등록된 날짜를 선택하면 사유 수정 또는 **휴관일 해제**를 할 수 있습니다.

등록은 해당 연도의 정확한 날짜에 적용되며 매년 반복되지 않습니다. 월요일 정기 휴관은 유지합니다. 공휴일은 관리자가 직접 등록합니다. 휴관일은 이용자 화면의 다음 조회부터 휴관 안내로 표시하고 막대/추천을 숨깁니다. 과거 날짜를 등록하면 해당 날짜는 통계의 원본 날짜에서도 제외됩니다. 원본 Excel/JSON은 수정하지 않습니다.

## 저장과 배포

운영 환경은 기존 Neon에 별도 관리 설정·집계 테이블을 추가하며, 출입 기록은 기존 JSON 버전 관리 그대로 사용합니다. Excel 게시/되돌리기 및 재배포로 휴관일/방문 집계가 초기화되지 않습니다. `neon/migrations/202610080001_operations.sql`을 소유자 역할로 먼저 적용하고 코드 배포합니다. 기존 확정 휴관일 3개는 초기 등록합니다.

로컬 단일 작업자 실행에서는 records 파일 옆 `*.operations.json`에 저장합니다. 여러 서버/작업자를 쓰는 운영 환경은 Neon을 사용합니다.

추가 API: `POST /api/v1/visit`(공개), `GET /api/v1/admin/traffic`, `GET /api/v1/admin/closures`, `PUT/DELETE /api/v1/admin/closures/{YYYY-MM-DD}`(관리자 세션 필수). PUT 본문은 `{"reason":"휴관 사유"}`입니다. 관리자 변경과 방문 POST는 외부 Origin 요청을 거부합니다.
