# ADE-49 이용자 화면 단순화

일반 이용자가 막대와 안내 멘트만 보고 시간대별 경향을 알 수 있도록 화면을 줄였습니다.

## 남긴 것

| 요소 | 내용 |
| --- | --- |
| 날짜 선택 | 오늘부터 7일 후까지. 범위 밖은 오류 안내 (기존 동작 유지) |
| 방문 안내 멘트 (`#guide`) | 날짜와 API `recommendation.message`. 휴관일·자료 부족은 회색 카드에 제목으로 표시 |
| 시간대별 막대 (`#chart`) | 높이 = `estimated_present` / 그날 최댓값, 색 = API `level` 그대로 |
| 범례 | 여유·보통·혼잡·자료 부족 |
| 막대 누르면 한 줄 | "12~13시 여유"처럼 시간과 단계만. 숫자는 보여 주지 않음 |
| 기준 한 줄 | 추정 체류 인원 기준이며 실시간 인원·좌석 점유율이 아니라는 안내 (ADE-41 문구 유지) |
| 하단 | 데이터 갱신 시각, 운영시간 안내 |

## 뺀 것

- 상세 예측표(`표로 보기`)
- 숫자 중심 카드: 큰 혼잡 단계 카드, 추천 시간 큰 숫자, 실제 집계(IN/OUT) 카드
- 같은 뜻을 반복하던 설명: 막대 사용법·색 기준 안내, 예측 기준 시각, 하단 공지 확인 문구
- 이용자 화면의 `/api/v1/stats` 호출 (API 자체는 그대로 둠)

## 상태별 표시

| 응답 | 안내 카드 | 막대 |
| --- | --- | --- |
| `forecast`/`partial`, 값 있음 | 날짜 + 멘트 | 색 막대, 값이 없는 시간만 회색 짧은 막대 |
| 모든 시간 값 없음 | 회색 카드, "자료 부족" + 멘트 | 전부 회색 |
| `closed` | 회색 카드, "휴관일" + 멘트 | 영역 숨김 |
| API 오류·다른 날짜 응답 | 숨김, 빨간 오류 문구 | 숨김 (이전 막대 남기지 않음) |

`estimated_present`가 없는 옛 응답은 예상 방문량으로 그리되, 기준 문구를 "예상 방문량"으로 바꿔 이름을 섞지 않습니다.

## 검증

```bash
python -m scripts.e2e          # 막대마다 hour·level·estimated_present를 API 응답과 대조, 휴관·범위 밖·오류·390px
python -m scripts.e2e_present  # ADE-40 fixture + 팀 서버 8일 + ADE-43 v2 fixture(open/insufficient/closed)
```

DOM 대조용으로 각 막대에 `data-hour`, `data-level`, `data-present`를 둡니다. 화면에는 보이지 않습니다.
