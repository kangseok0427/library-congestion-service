# 구현 및 검증 결과 (2026-09-15)

## 처음 보는 팀원을 위한 동작 설명

표준 records를 검증해 두 게이트 시간대 입장량을 합산합니다. 일일 원본 합계는 게이트마다 한 번만 합산합니다.
과거 4주 같은 요일·시간 평균과 fallback으로 예측하며, API를 통해 날짜별 웹 화면에 전달합니다.
새 스냅샷은 검증 성공 후 교체되고 다음 API 요청/웹 새로고침부터 반영됩니다.

## 실제 검증

- Python 3.14.5 / FastAPI 0.141.1 / openpyxl 3.1.5 / Chromium 151.
- `python -m pytest -q`: 26 passed. 의존성 deprecation 경고 2개, 실패 없음.
- `python -m scripts.e2e`: 합성 records → API → 브라우저 PASS.
- 실제 Excel → records: 1,836행 × 16시간 = 29,376건.
- 실제 파일에서 생성한 records로 E2E PASS (`--date 2026-09-10`).
- 16개 예측 행/막대, 실제 집계 값, records 교체 후 실제값/예측값 변화 확인.
- 390px 모바일 가로 넘침 없음, 데스크톱/모바일 화면 확인.
- 잘못된 입력 파일 교체 시 오류 표시 및 이전 숫자 제거 확인.
- rebuild 검증 실패 시 이전 정상 파일 보존 확인.
- 중복, 음수, 결측, 소수, 잘못된 날짜, 게이트 누락, partial, 0, fallback,
  미래 데이터 배제, backtest 누수 방지, 연속 추천 구간 및 당일 마감 이후를 검증.

최근 28개 완전한 수집일: 2026-08-07~2026-09-09 (28일은 달력상 연속 28일이 아닙니다).

baseline이 단순 비교 모델보다 낮은 오차를 보여 설명 가능한 baseline을 유지했습니다.

## 데이터 품질 주의

- 일일 원본 합계 vs 시간대 합계 경고 3,626건을 보존했습니다. 임의 보정하지 않았습니다.
- 2026-09-10은 부분 수집일로 명시했습니다.
- 해당 날짜의 일일 원본 IN은 122, 시간대 IN 합계는 103입니다. 서로 다른 수치임을 웹에 표시합니다.
- partial과 한쪽 게이트 누락은 예측 학습에서 제외됩니다.
- 운영시간/휴관일 달력이 아직 연결되지 않아 추천은 수집 시간대의 패턴 후보입니다.
  웹에서 운영시간 확인을 안내합니다. 실제 방문 가능 시간 필터는 운영정보 담당자와 통합해야 합니다.
- 박수용님 저장소는 현재 연결에서 404로 직접 코드 검증을 하지 못했습니다.
  이 결과는 독립 구현과 실제 원본 검증이며 팀원 코드의 테스트 통과를 대신 주장하지 않습니다.
- 원본 Excel·실제 records·상세 품질 보고서·브라우저 실데이터 캡처는 Git 추적에서 제외했습니다.
